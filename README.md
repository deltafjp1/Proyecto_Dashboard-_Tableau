# YouTube Trending Dashboard | Tableau Business Intelligence Project

🇪🇸 Dashboard interactivo en Tableau para analizar tendencias de videos de YouTube por categoría, región y periodo de tiempo.
🇬🇧 Interactive Tableau dashboard to analyze YouTube video trends by category, region, and time period.

---

## Descripción / Overview

🇪🇸
Este proyecto presenta un dashboard interactivo desarrollado en Tableau para analizar videos en tendencia de YouTube. El objetivo es identificar patrones de comportamiento por categoría, país/región y fecha, con el fin de apoyar decisiones relacionadas con marketing de contenidos, análisis de audiencias y estrategia digital.

🇬🇧
This project presents an interactive Tableau dashboard developed to analyze trending YouTube videos. The goal is to identify behavioral patterns by category, country/region, and date in order to support decisions related to content marketing, audience analysis, and digital strategy.

---

🇪🇸
Analizar qué categorías de videos aparecen con mayor frecuencia en tendencias, cómo varían por región y qué patrones pueden ser útiles para entender el comportamiento del contenido digital.

🇬🇧
Analyze which video categories appear most frequently in trends, how they vary by region, and which patterns can help understand digital content behavior.
